ArtNet Devices

Graba el firmware directamente desde Google Chrome y convierte la placa en un nodo Art‑Net de GPIO digitales y PWM.

1. Conecta el ESP32 por USB.

2. Pulsa instalar y selecciona el puerto serie correcto. El instalador identifica el chip antes de elegir el firmware: no tienes que seleccionar ningún modelo.

3. Al acabar se abrirá Configurar por USB automáticamente. Así eliges el universo y cada GPIO/canal, digital o PWM sin cambiar la red del ordenador.

Usa Chrome o Edge. El C3/C6 USB‑JTAG no necesita drivers si el puerto aparece.


  

  

    Controladores USB
    
ESP32-C3 y ESP32-C6 por USB JTAG/serial: usan el controlador CDC nativo del sistema; no instales un driver de terceros en macOS, Linux ni Windows 10/11 si el puerto ya aparece.

    
CH340, CH341 o CH9102: instala el controlador WCH. CP210x: instala el VCP de Silicon Labs. Son habituales en ESP32 clásicos y ESP8266/Wemos; confirma el chip impreso en tu placa o el nombre del puerto.

    
En Windows, macOS Intel, macOS Apple Silicon y Linux la web funciona con Chrome/Edge mediante Web Serial. La app de escritorio usa el puerto serie del sistema y no depende de Chrome.

  

  
Configurador único recomendado: USB en Chrome →

  
Incluye búsqueda de redes, IP, universo, GPIO/canales y PWM sin desconectar el ordenador de Internet. El botón Change Wi‑Fi del cuadro de Espressif sólo admite SSID manual: usa este configurador para escanear.

  
El portal de red permanece siempre disponible: únete al Wi‑Fi ArtNet-Devices-Setup y abre http://192.168.4.1, incluso después de guardar otra red. Si el dispositivo está en tu Wi‑Fi habitual, también puedes usar su IP o su nombre artnet-devices.local. El portal cautivo se abrirá automáticamente en los sistemas compatibles.

  Detecta la familia de chip y ofrece firmware para ESP32‑C6, C3, C2, ESP32, S2, S3 y ESP8266. El firmware conoce el perfil instalado y sólo permite GPIO seguros.
