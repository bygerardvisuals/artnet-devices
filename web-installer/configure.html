Abrir configurador

Conecta el ordenador a la red Wi‑Fi ArtNet-Relay-Setup creada por el ESP32‑C6 tras instalarlo. El panel que se abre permite configurar Wi‑Fi, nombre, universo, canal, GPIO, polaridad y actualizar el firmware por OTA.

Cuando el dispositivo ya esté conectado a tu red, usa su IP o http://nombre.local. El configurador se abre directamente desde el ESP32 para que funcione también desde GitHub Pages.
