Configurar por USB

Igual que el instalador: conecta el ESP32 por USB, pulsa conectar y ajusta el relay sin cambiar la Wi‑Fi del ordenador.

Conecta el C6 por USB y pulsa “Conectar por USB”.

Identidad y Art‑Net

Salida de relé

DMX 0–127 apaga; 128–255 enciende. Para negro/blanco envía 0/255.

Wi‑Fi

La contraseña guardada nunca se lee ni se muestra por USB.

Dirección IP

Si no se activa, el router asignará la IP por DHCP.

Guardar

El dispositivo se reiniciará al guardar. La conexión USB se liberará automáticamente.
